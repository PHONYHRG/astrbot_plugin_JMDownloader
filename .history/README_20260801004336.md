# AstrBot JM下载器

> 基于 AstrBot 的禁漫本子下载插件，输入 `jm123` 即可自动下载并发送到群聊，支持 PDF / ZIP 双格式和多章节选择。

---

## ✨ 功能特性

- 🗣️ **灵活触发**：支持 `jm123`、`JM123`、`本子123` 等多种写法，也支持纯数字（4位及以上）自动识别。
- 📄 **双传输模式**：可选择输出 **PDF**（默认）或 **ZIP 压缩包**，满足不同查看习惯。
- 📚 **多章节支持**：可下载指定章节（如 `jm123 2`）或合并全部章节（`jm123 full`）。
- 🖼️ **原始尺寸 PDF**：PDF 中每一页使用图片原始尺寸，封面与内容页不再变形。
- 🗑️ **智能清理**：发送后自动删除输出文件（PDF/ZIP）或保留图片文件夹，支持启动时清理残留目录。
- ⚡ **异步下载**：不阻塞主事件循环，支持并发请求。
- 🎛️ **可配置**：存储路径、群组白名单、清理策略等均可通过 WebUI 调节。

---

## 📋 配置说明

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `storage_path` | string | `""` | 下载临时存储目录，留空则使用插件数据目录 |
| `auto_delete` | bool | `false` | 发送完成后是否删除图片文件夹（保留输出文件） |
| `delete_pdf_after_send` | bool | `true` | 发送完成后是否删除输出文件（PDF/ZIP） |
| `clear_on_startup` | bool | `false` | 插件加载时自动清理临时目录和残留图片（释放空间） |
| `option_file` | string | `""` | `jmcomic` 自定义配置文件路径（YAML），留空使用内置默认配置 |
| `allowed_groups` | list | `[]` | 允许使用插件的群组 ID 列表，为空则所有群生效 |

---

## 🗣️ 命令格式

新格式：`jm<ID> [传输方式] [章节]`

- **传输方式**：`pdf`（默认）或 `zip`（发送图片压缩包）
- **章节**：`full`（全部章节）、数字（指定章节，从1开始）、不填（默认第一章）

### 使用示例

| 命令 | 说明 |
|------|------|
| `jm123` | 下载第一章，PDF 格式 |
| `jm123 zip` | 下载第一章，ZIP 压缩包 |
| `jm123 2` | 下载第二章，PDF 格式 |
| `jm123 zip 2` | 下载第二章，ZIP 压缩包 |
| `jm123 full` | 下载全部章节并合并为 PDF |
| `jm123 zip full` | 下载全部章节并打包为 ZIP |

> 参数顺序可调，插件会自动识别 `pdf`/`zip` 和 `full`/数字。

## 📦 安装与使用

1. 将插件文件夹 `astrbot_plugin_JMDownloader` 放入 AstrBot 的 `plugins` 目录。
2. 重启 AstrBot，依赖（`jmcomic`, `pyyaml`, `Pillow`, `reportlab`）会自动安装。
3. 在 WebUI 中根据需要配置 `storage_path`、`allowed_groups`、`clear_on_startup` 等。
4. 在群聊中发送命令测试。

---

## ⚠️ 注意事项

- 确保运行环境可访问禁漫域名（可能需要配置代理）。
- 大型本子输出文件可能超过平台文件大小限制（如 QQ 限制 200MB）。
- 开启 `clear_on_startup` 会删除所有以数字命名的目录，请确认 `storage_path` 内无其他重要数据。
- 若使用自定义 `option_file`，请确保其 `dir_rule.rule` 与插件兼容（推荐 `Bd_Aid` 或 `Bd_Aid_Pid`）。
