# AstrBot JM下载器

> 基于 AstrBot 的禁漫本子下载插件，输入 `jm123` 即可自动下载并合并为 PDF 发送到群聊。

## 功能特性

- 🗣️ **自然语言触发**：支持 `jm123`、`JM123`、`本子123`，也支持纯数字（4位及以上）自动识别。
- 📄 **自动 PDF 合成**：下载完成后自动按顺序合并为 PDF，方便移动端阅读。
- 🗑️ **智能清理**：发送后自动删除 PDF（保留图片）或保留 PDF 删除图片，可通过配置灵活控制。
- ⚡ **异步下载**：不阻塞主事件循环。
- 🎛️ **可配置**：支持自定义存储路径、群组白名单、清理策略等。

## 配置

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `storage_path` | string | `""` | 存储目录，留空则使用插件数据目录 |
| `auto_delete` | bool | `false` | 是否删除图片文件夹（保留 PDF） |
| `delete_pdf_after_send` | bool | `true` | 是否发送后删除 PDF（保留图片） |
| `option_file` | string | `""` | `jmcomic` 自定义配置文件 |
| `allowed_groups` | list | `[]` | 允许的群组 ID 列表 |

## 命令

- `jm123` / `JM123` / `本子123`
- 纯数字（≥4位）自动识别

## 安装

将插件放入 `plugins` 目录，重启 AstrBot 即可。依赖会自动安装。

## 注意事项

- 确保网络可访问禁漫域名（可能需要代理）。
- 大型本子 PDF 可能超过平台文件大小限制。
