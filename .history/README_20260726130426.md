# AstrBot JM下载器

> 基于 AstrBot 的禁漫本子下载插件，输入 `jm123` 即可自动下载并合并为 PDF 发送到群聊。

---

## 📖 简介

**astrbot_plugin_JMDownloader** 是一个为 AstrBot 开发的群聊插件，允许用户通过自然语言命令（如 `jm123`、`本子456`）直接下载禁漫天堂的指定本子，并自动将图片合并为 PDF 文件发送到群聊。插件基于 `jmcomic` 库实现下载，使用 `reportlab` 生成 PDF，全程无需手动操作。

---

## ✨ 功能特性

- 🗣️ **自然语言触发**：支持 `jm123`、`JM123`、`本子123` 等命令，也支持纯数字（4位及以上）自动识别。
- 📄 **自动 PDF 合成**：下载完成后自动将图片按顺序合并为 PDF，方便移动端阅读。
- ⚡ **异步下载**：使用 `asyncio.to_thread` 避免阻塞主事件循环。
- 🗑️ **自动清理**：发送 PDF 后自动删除原始图片文件夹，节省磁盘空间（可配置）。
- 🎛️ **可配置**：支持自定义存储路径、群组白名单、是否自动删除等。
- 🔒 **无冲突依赖**：使用 `reportlab` 替代 `img2pdf`，避免与 `pikepdf` 的 nanobind 冲突。

---

## ⚙️ 配置说明

在 AstrBot WebUI 中，插件提供以下配置项：

| 配置键 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `storage_path` | string | `""` | 下载临时存储目录（绝对路径或相对路径）。留空则自动使用 `data/plugin_data/jm_downloader/downloads/` |
| `auto_delete` | bool | `true` | 发送完成后是否自动删除下载的图片文件夹（PDF 文件保留） |
| `option_file` | string | `""` | `jmcomic` 自定义配置文件路径（YAML 格式），留空则使用内置默认配置（仅下载图片，不触发任何插件） |
| `allowed_groups` | list | `[]` | 允许使用该插件的群组 ID 列表（字符串格式），为空则所有群生效 |

---

## 🗣️ 命令说明

| 触发词 | 示例 | 说明 |
|--------|------|------|
| `jm<数字>` / `JM<数字>` | `jm123` | 下载指定本子，生成 PDF 并发送 |
| `本子<数字>` | `本子456` | 同上 |
| 纯数字（4位及以上） | `123456` | 自动识别为本子 ID，执行下载 |

> **提示**：本子 ID 是禁漫天堂的专辑 ID（Album ID），通常是 5~7 位数字。请确保 ID 有效，且网络可访问禁漫域名（可能需要代理）。

## 📦 安装与使用

### 依赖

- AstrBot v4.26.7 及以上
- Python 3.9+（推荐 3.12）
- 自动安装依赖：`jmcomic`, `pyyaml`, `Pillow`, `reportlab`

### 安装步骤

1. 将插件文件夹 `astrbot_plugin_JMDownloader` 放入 AstrBot 的 `plugins` 目录。
2. 重启 AstrBot，插件会自动安装依赖并加载。
3. 在 WebUI 中根据需要配置 `storage_path`、`allowed_groups` 等。
4. 在群聊中发送 `jm123`（替换为真实 ID）测试。

---

## 🔧 工作原理

1. **命令识别**：通过正则匹配用户消息，提取本子 ID。
2. **下载**：调用 `jmcomic.download_album()` 下载图片到 `storage_path/album_id/`。
3. **PDF 合成**：遍历下载目录，按文件名数字排序图片，使用 `reportlab` 逐页生成 PDF。
4. **发送**：将 PDF 文件通过 `File` 组件发送到群聊。
5. **清理**：如果 `auto_delete` 为 `true`，删除图片文件夹，保留 PDF。

## ⚠️ 注意事项

- **网络环境**：确保运行 AstrBot 的服务器可访问禁漫天堂域名（可能需要配置代理）。
- **文件大小**：大型本子 PDF 可能超过平台文件大小限制（如 QQ 限制 200MB），请注意。
- **ID 有效性**：命令 `jm` 后必须跟有效的本子 ID，否则下载失败。
- **并发下载**：插件未限制同时下载数量，请谨慎使用，避免对目标服务器造成压力。
- **依赖冲突**：本插件已规避 `pikepdf`，但若其他插件也使用了 `pikepdf`，仍可能引起冲突，建议优先测试。

## 🐛 常见问题

### Q: 下载失败，提示 `未注册的plugin: export_pdf`
A: 这是旧配置文件残留，插件已自动修复，删除 `default_option.yml` 并重启即可。

### Q: PDF 页面顺序错乱或重复
A: 已修复图片排序和去重逻辑，请更新到最新代码。

### Q: 发送文件报错 `File.__init__() missing 1 required positional argument: 'name'`
A: 使用 `File(file=str(pdf_path))` 方式，已在最新版本中修正。

### Q: 无法加载 `reportlab`
A: 请确保使用 AstrBot 的 Python 环境安装依赖：`"D:\bot\AstrBot\backend\python\python.exe" -m pip install reportlab Pillow`
